  ## Project: Study Planner

### Project Description
Study Planner is a web application designed to help online students organize and manage their courses and assignments. Students can register and log in to their accounts, add courses, manage assignments, set due dates and priorities, and track their progress.

The dashboard will display assignments due during the week, helping students stay organized and keep up with their schoolwork.

### Main Features
- User registration and login.
- Create, view, edit, and delete courses.
- Create, view, edit, and delete assignments.
- Set assignment due dates and priorities.
- View upcoming assignments on a dashboard.
- Mark assignments as completed.
- Keep each student's planner private.

### Target Audience
Online students who balance school, work, and other responsibilities.
